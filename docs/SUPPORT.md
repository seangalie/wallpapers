# Getting help with Sean's Wallpaper Archive

Start with the [README](../README.md) for browsing and downloading images, and
the [organization guide](ORGANIZATION.md) for categories and filenames.
Search the [existing issues](https://github.com/seangalie/wallpapers/issues?q=is%3Aissue)
before opening a new one.

## Where to go

| What you need | Where it goes |
| --- | --- |
| Help choosing or applying a wallpaper | [Support question](https://github.com/seangalie/wallpapers/issues/new?template=04_support_question.yml) |
| A broken image, incorrect name, or misplaced file | [Bug report](https://github.com/seangalie/wallpapers/issues/new?template=01_bug_report.yml) |
| A new wallpaper or collection suggestion | [Feature request](https://github.com/seangalie/wallpapers/issues/new?template=02_feature_request.yml) |
| A creator credit or source correction | A [bug report](https://github.com/seangalie/wallpapers/issues/new?template=01_bug_report.yml) or a pull request |
| A repository or tooling improvement | [Codebase improvement](https://github.com/seangalie/wallpapers/issues/new?template=03_codebase_improvement.yml) |
| A security vulnerability | Follow the private [security reporting policy](SECURITY.md) |
| An image or documentation contribution | [Contributing guide](CONTRIBUTING.md) |

## Include useful details

Give the image's full repository path and describe the problem or proposed
correction. For a source or creator credit, include the original URL. For a
display issue, include your operating system, screen resolution, monitor layout,
and the steps you took to apply the wallpaper. Include a commit or release
reference when it helps identify the copy you downloaded.

## What to expect

I look after this archive in my spare time, so I answer when I can. There's no
guaranteed response time or paid support.

Inactive issues are marked stale after 60 days and closed 14 days later unless
they carry an exempt label. Update the issue if it still needs attention; you
can open a follow-up if a closed issue remains relevant.
